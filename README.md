# VoiceTyper by iLoveMac — releases

Distribution artifacts and the Sparkle update feed for **VoiceTyper by iLoveMac**, a macOS
push-to-talk voice-typing app that transcribes 100% on-device.

**Download:** https://updates.rasulov.net · or the [Releases](../../releases) tab.

This repository contains no source code — only the published installer, the update feed, and
release notes. The application source is private.

| Path | What it is |
|---|---|
| `appcast.xml` | The Sparkle update feed. Every installed copy of VoiceTyper polls this. |
| `appcast-staging.xml` | Pre-release feed, used to test an update before it reaches users. |
| `release-notes/` | Per-version HTML, rendered inside VoiceTyper's update dialog. |
| Releases | `VoiceTyper-<version>.dmg` (install) and `.zip` (Sparkle update payload). |
