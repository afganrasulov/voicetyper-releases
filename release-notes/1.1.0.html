Version 1.1.0

Added

  • Automatic updates. VoiceTyper now checks once a day for a new version and can install it itself — no more re-downloading by hand.
  • A "Check for Updates" control in Settings ▸ Support and in the VoiceTyper menu.

Changed

  • VoiceTyper is now distributed as a signed, notarized disk image: download, drag to Applications, open. No security warnings, no right-click workaround.

Fixed

  • The microphone reconnection retry could outlive the recorder that scheduled it.
  • Several settings labels still used developer jargon instead of plain language.
